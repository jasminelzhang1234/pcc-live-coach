# Privacy Policy

Last updated: 2026-09-03

## Summary

| Data type | Where it stays |
|---|---|
| Microphone audio (raw PCM) | **Your machine only.** Never sent to any cloud. |
| Speech-to-text transcripts | **Your machine only.** Generated by local FunASR inference. |
| Conversation text sent to LLM | Sent to **MiniMax API** over HTTPS (configurable endpoint). **You can change the LLM endpoint** to point to a self-hosted LLM if you want full local inference. |
| TTS audio | Generated by **MiniMax T2A API** (configurable endpoint). |
| Persona data | Stored locally in `personas/` directory. |
| Real practice audio | Stored locally in `practice-logs/真人练习/` (gitignored). |
| Per-session artifacts (transcript / assessment / tracker analysis) | Stored locally in `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/` (gitignored). |

---

## Detailed handling

### 1. Audio capture

The browser captures microphone audio using the Web Audio API at 16kHz mono PCM. Audio frames are sent over WebSocket to the local backend (`127.0.0.1:8765` by default). The backend does not forward audio to any external service for speech recognition.

### 2. Speech-to-text (STT)

Speech recognition runs **locally** using [FunASR](https://github.com/modelscope/FunASR) with the `iic/SenseVoiceSmall` model. Model weights are downloaded once from ModelScope hub (~220 MB) and cached in `~/.cache/modelscope/`. After the first download, no network connection is required for STT.

**No audio or transcript is sent to any third-party STT service** (e.g., Alibaba Cloud ASR, iFlytek, Google Speech). If you modify the backend to use such a service, you do so at your own risk and must update this policy accordingly.

### 3. Language model (LLM)

Conversation text is sent to a **language model endpoint** to generate coach responses. The default endpoint is **MiniMax API** (configured via `LLM_API_KEY` and `LLM_BASE_URL` environment variables). MiniMax processes the text under their own privacy policy ([minimaxi.com](https://minimaxi.com)).

**To avoid sending any data to MiniMax:**
- Set `LLM_BASE_URL` to a self-hosted OpenAI-compatible endpoint (e.g., a local Llama, Qwen, or other model).
- Set `LLM_API_KEY` to any non-empty string (the local server will not validate it).

In self-hosted mode, **no conversation leaves your machine**.

### 4. Text-to-speech (TTS)

Coach responses are synthesized via the **MiniMax T2A API** (`speech-2.6-hd` by default). The text of each response is sent to MiniMax over HTTPS, and audio is streamed back. MiniMax processes the text under their own privacy policy.

**To avoid sending any data to MiniMax:**
- Use a self-hosted TTS endpoint compatible with the MiniMax T2A WebSocket protocol (planned).
- Or disable voice output entirely (text-only mode).

### 5. Persona library

Personas are Markdown files stored in `personas/`. They are read locally by the coachee agent. They are not transmitted anywhere.

### 6. Real practice session artifacts

Real (non-persona) practice sessions produce these local files:
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/audio/<session>.mp3` — original audio (never uploaded)
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/01-<topic>.md` — cleaned transcript (coach-authored)
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/02-评估.md` — PCC 37-marker assessment
- `progress/tracker-real-sessions.csv` — single-row-per-session summary for trending analysis

All files are stored on your local disk and are **not** uploaded anywhere by the tool.

### 7. Append to tracker CSV

Rhythm features are appended to `progress/tracker-real-sessions.csv` for the existing analysis pipeline. This file stays local.

### 8. No telemetry

This tool does **not** include telemetry, analytics, crash reporting, or any other outbound data collection. There is no "phone home".

### 9. No cookies, no auth

The tool runs on `127.0.0.1` only (no public exposure by default). There is no user authentication, no cookies, no sessions to manage.

---

## What we recommend

If you are practicing with sensitive real client material (which you should generally **avoid** for privacy reasons — use AI personas for practice, real clients for credentialing):

- Run on an air-gapped machine.
- Use a self-hosted LLM and TTS.
- Delete session logs after each session.
- Disable cloud backups of `practice-logs/` (covers both AI persona reports and real-session artifacts) and `progress/`.

---

## Changes to this policy

If the tool's privacy posture changes (e.g., optional cloud feature added), this document will be updated and the change noted in `CHANGELOG.md`.

# 隐私策略

最后更新:2026-09-03

## 概要

| 数据类型 | 留在哪里 |
|---|---|
| 麦克风音频(原始 PCM) | **仅你的机器。** 不会上传到任何云。 |
| 语音转文字转写 | **仅你的机器。** 由本地 FunASR 推理生成。 |
| 发给 LLM 的对话文本 | 通过 HTTPS 发往 **MiniMax API**(可配置端点)。**你可以修改 LLM 端点**指向自托管 LLM 以实现完全本地推理。 |
| TTS 音频 | 由 **MiniMax T2A API**(可配置端点)生成。 |
| 人格数据 | 存储在本地 `personas/` 目录。 |
| 真人练习音频 | 存储在本地 `practice-logs/真人练习/`(gitignored)。 |
| 逐场派生产物(逐字稿 / 评估 / tracker 分析) | 存储在本地 `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/`(gitignored)。 |

---

## 详细说明

### 1. 音频采集

浏览器使用 Web Audio API 以 16kHz 单声道 PCM 采集麦克风音频。音频帧通过 WebSocket 发送到本地后端(默认 `127.0.0.1:8765`)。后端不会将音频转发到任何外部服务进行语音识别。

### 2. 语音转文字(STT)

语音识别**本地运行**,使用 [FunASR](https://github.com/modelscope/FunASR) 的 `iic/SenseVoiceSmall` 模型。模型权重从 ModelScope hub 一次性下载(~220 MB)并缓存到 `~/.cache/modelscope/`。首次下载后,STT 无需任何网络连接。

**音频和转写文本不会发送到任何第三方 STT 服务**(如阿里云 ASR、讯飞、Google Speech)。如果你修改后端使用此类服务,你需自行承担风险,并相应更新本策略。

### 3. 语言模型(LLM)

对话文本被发送到一个**语言模型端点**以生成教练回应。默认端点是 **MiniMax API**(通过 `LLM_API_KEY` 和 `LLM_BASE_URL` 环境变量配置)。MiniMax 按其自己的隐私策略处理文本([minimaxi.com](https://minimaxi.com))。

**要避免向 MiniMax 发送任何数据:**
- 将 `LLM_BASE_URL` 设置为自托管的 OpenAI 兼容端点(例如本地的 Llama、Qwen 或其他模型)
- 将 `LLM_API_KEY` 设置为任意非空字符串(本地服务器不会校验)

在自托管模式下,**所有对话都不离开你的机器**。

### 4. 语音合成(TTS)

教练回应通过 **MiniMax T2A API**(默认 `speech-2.6-hd`)合成。每条回应的文本通过 HTTPS 发往 MiniMax,音频流式返回。MiniMax 按其自己的隐私策略处理文本。

**要避免向 MiniMax 发送任何数据:**
- 使用与 MiniMax T2A WebSocket 协议兼容的自托管 TTS 端点(计划中)
- 或完全禁用语音输出(仅文字模式)

### 5. 人格库

人格是 Markdown 文件,存储在 `personas/`。它们由陪练 agent 本地读取,不会被传输到任何地方。

### 6. 真人练习会话产物

真人(非 persona)练习会话产生以下本地文件:
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/audio/<session>.mp3` —— 原始音频(绝不外传)
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/01-<议题>.md` —— 整理后逐字稿(本人撰写)
- `practice-logs/真人练习/<YYYY-MM-DD>-session-NN/02-评估.md` —— PCC 37-marker 评估报告
- `progress/tracker-real-sessions.csv` —— 逐场摘要,供 trending 分析使用

所有文件存储在你的本地磁盘上。本工具**不会**将它们上传到任何地方。

### 7. 追加到 tracker CSV

节奏特征被追加到 `progress/tracker-real-sessions.csv` 以供现有分析流水线使用。此文件保留在本地。

### 8. 无遥测

本工具**不包含**遥测、分析、崩溃报告或任何其他出站数据收集。**没有"回拨"**。

### 9. 无 cookie,无认证

工具仅在 `127.0.0.1` 运行(默认不对外暴露)。没有用户认证、cookie 或会话管理。

## 我们建议

如果你使用敏感的真实客户材料进行练习(出于隐私考虑,你通常应该**避免**这种情况 —— AI 人格用于练习,真人客户用于认证):

- 在气隙隔离的机器上运行
- 使用自托管 LLM 和 TTS
- 每次会话后删除会话日志
- 禁用 `practice-logs/`(覆盖 AI persona 报告和真人练习产物)和 `progress/` 的云备份
