# PCC 表现评估判定规则

> 本文件定义 pcc-assessor 的判定尺度与阈值。
> 判定依据见 `pcc-markers-2025.md`，丢分模式见 `failure-patterns.md`。

---

## 1. 三档判定

| 符号 | 含义 | 判定条件 |
|---|---|---|
| ✔ | 明确证据 | 能引用逐字稿原话，且该原话**独立成立**，无需善意解读 |
| △ | 部分证据 | 动作出现但不完整（只问不跟进、总结但未确认、有邀请但客户未回应） |
| ✘ | 未见证据 | 无可引用原话 |

---

## 2. 三条铁律

1. **没有可引用的逐字稿原话 = ✘。** 不得以"教练显然是想……""从上下文看应该是"作为证据。
2. **只认客户听得到的话与可观察行为**，不认教练的意图、心理活动、准备工作。
3. **默认怀疑立场**：先假设不成立，由证据推翻。模糊地带向下取整，绝不向上。

---

## 3. 能力 1（展现道德实践）— 红线判定，不计分

出现以下任一即**整体不通过**，与其余 36 条命中多少无关：

| 红线 | 逐字稿识别特征 |
|---|---|
| 给出建议、方案、诊断，或替客户做决定 | "我建议""你应该""你可以试试""如果是我会……" |
| 滑向顾问 / 培训师 / 心理治疗角色 | 讲解方法论、传授模型、分析童年成因 |
| 未经允许把话题带向客户未同意探索的领域 | 教练自行转向家庭、健康、创伤等未被邀请的议题 |
| 在会话中评判客户 | "这样想是不对的""你太苛刻了" |

**注意**：建议常常裹在问句里——"你有没有想过跟他谈一次？"实质是建议，判为红线触发。
判定方法：把问号去掉，如果剩下的是一个主张，就是建议。

## 4. 能力 2（体现教练心态）— 借用 11 条观测

**观测集**：4.1、4.3、4.4、5.1、5.2、5.3、5.4、6.1、6.5、7.1、7.5

单独汇总这 11 条的命中情况，给出"教练心态是否被观测到"的结论。
ICF 原文明确：该能力的完整评估还包含持续学习、反思实践、会前准备，
这些**无法在单次会话中被捕捉**，会在 ICF 资格笔试中考核（占比 13%）。
因此本项汇总只回答"本场对话中，教练心态的可观测部分是否呈现"。

**参考线**：11 条中命中 ≥7 条视为呈现良好，5–6 条为边缘，≤4 条为未呈现。

### 4.1 教练意识与教练状态【本土督导增量】

**本土视角**（来自 PCC 考官本土）补充两个独立维度。
这两个维度不增加新 marker，但解释了 11 条观测背后的"为什么"——
同一行为可能出自不同的意识 / 状态，判定时需透过动作看内在。

**6 种教练意识**

| 意识 | 含义 | 覆盖 markers |
|---|---|---|
| 合约意识 | 围绕客户的目标 / 成果展开 | 3.x, 5.2, 7.3, 8.1, 8.3 |
| 伙伴意识 | 客户为中心、协同决定 | 4.x, 5.3, 5.4, 6.2, 7.8, 8.8, 8.9 |
| 借事修人 | 透过事去看人（本土概念）| 5.1, 6.4, 6.5, 7.4, 8.2 |
| 当下意识 | 在场、回应此刻 | 6.1, 6.3, 7.1, 7.5 |
| 成果意识 | 始终围绕客户想要的 | 5.2, 7.3, 8.1, 8.3 |
| 落地意识 | 把觉察转成行动与障碍 | 8.5, 8.6, 8.7 |

**6 种教练状态**

| 状态 | 含义 | 关键支撑的 markers |
|---|---|---|
| 好奇 | 对客户本人 / 处境真正感兴趣 | 5.4, 6.2, 6.3 |
| 连接 | 与客户同在、回应客户当下 | 4.2, 5.1, 7.2 |
| 尊重 | 接纳客户的一切表达 | 4.1, 4.3, 4.4 |
| 连接力 | 与客户建立超越表面的深度连接 | 5.1, 7.2 |
| 空间力 | 留白、允许沉默、给客户时间 | 5.5, 6.6, 7.6, 7.8 |
| 勇气力 | 敢于碰人、敢于分享观察 | 7.1, 7.5 |

**使用方式**：能力 2 的判定不止数 11 条 marker，
还需在报告中点出**最显著的 1–2 种意识**和**最显著的 1–2 种状态**。
这是给客户的额外洞察：知道"做到了什么"也知道"是怎么做到的"。

## 5. 达标阈值（校准估计，非 ICF 官方公开数值）

ICF 从未公开每项能力的最低 marker 达标条数，官方仅表述为
"a minimum number of these markers will need to be demonstrated"。
以下为本系统的保守估计，**用于自我训练，不得对外宣称为 ICF 判定**。

| 能力 | 总条数 | 估计最低达标 | 必命中项 |
|---|---|---|---|
| 3 建立并维护协议 | 4 | 3 | 3.1、3.4 |
| 4 培养信任与安全 | 4 | 2 | — |
| 5 保持临在 | 5 | 3 | — |
| 6 积极聆听 | 7 | 4 | 6.7 |
| 7 唤起觉察 | 8 | 5 | 7.2 或 7.3 至少一条 |
| 8 促进客户成长 | 9 | 5 | 8.5、8.9 |

**计分方式**
- ✔ 计 1 条，△ 计 0.5 条，✘ 计 0
- 必命中项若为 ✘，该能力直接判"未达标"，不论总数是否够
- 任一能力未达标 → **整体判"未达标"**（不是总分制，不能靠强项补弱项）

**阈值调整记录**
| 日期 | 调整内容 | 原因 |
|---|---|---|
| 2026-08-21 | 初始设定 | 基于 2025 版 markers 分布与常见评估实践的保守估计，待任务 6 校准 |

## 6. 报告强制声明

每份全评报告结尾必须**原样包含**以下文字：

> 本报告阈值为基于督导基线的校准估计，非 ICF 官方公开数值，
> 不构成 ICF 认证结果的预测或承诺。

## 7. 结构性降档规则

以下情形即使有原话证据，也须降档处理：

| 情形 | 处理 |
|---|---|
| 3.1 未命中 | 5.2、8.1 自动 ✘（无目标则无从回应目标、无从对照进展） |
| 纯文字逐字稿，无停顿标注 | 5.5 判 ✘，报告中注明"需音频核实" |
| 纯文字逐字稿，无非语言信息 | 6.4 判 ✘，报告中注明"文字模式受限" |
| 教练字数占比 ≥40% | 7.8 判 ✘；30–40% 判 △ |
| 分享观察后客户否定，教练再推一次 | 7.5 判 ✘，且 4.4 降至 ✘ |
| 总结后未给客户确认机会 | 6.7 降至 △，且 4.4 不得因此条命中 |
| 会话结尾由教练单方面宣布 | 8.9 判 ✘，无解释空间 |

## 8. 必命中项速查（一票否决点）

| Marker | 内容 | 为什么是否决点 |
|---|---|---|
| **3.1** | 确认本次会话想达成什么 | 无目标则 5.2、8.1 连锁失效 |
| **3.4** | 定义需要处理什么 | 最常被跳过，直接决定探索是否有着力点 |
| **6.7** | 简洁地反映或总结 | PCC 对话不可能一次有效反映都没有 |
| **7.2 或 7.3** | 探索超越当前认知 | PCC 与 ACC 的分水岭 |
| **8.5** | 设计会后的思考、反思或行动 | 无设计则整场停留在探索层 |
| **8.9** | 共同决定如何结束会话 | 判定极明确，补救成本极低 |
