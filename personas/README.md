## 配套练习 SOP

1. 用 VS Code 切到 `pcc-coachee` agent
2. 告诉它"开始陪练,选 vec-08"
3. 它会读 [vec-08.md](vec-08.md) 并开始扮演
4. 你做教练,正常对话
5. 结束后告诉它"全评"
6. 它会切到 `pcc-assessor` 视角给出判定
