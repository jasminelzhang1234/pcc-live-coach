一、设计原则

多命中思维：与其问 18 句各打 1 个 marker，不如用 10 句每句打 2–4 个 marker。 同一时段内，一个精心设计的并置句 = 一句话同时唤醒 6.1 / 6.7 / 7.3 / 4.4 四条 marker。
6 个必命中项（3.1 / 3.4 / 6.7 / 7.2 或 7.3 / 8.5 / 8.9）各需至少一道专属问句保底——其他 marker 由多命中问题顺带拿到。
11 条整场型 marker（4.1 / 4.3 / 4.4 / 5.1 / 5.2 / 5.3 / 5.4 / 6.1 / 6.6 / 7.6 / 7.7 / 7.8）靠问法本身拿到——用"客户原词 + 一次一个 + 不替客户定义"自动命中。

二、必命中项速查（考前 30 秒扫一眼）

Marker 保底问句 背诵口诀 为什么是否决点
3.1 「今天这 45 分钟，你最想带走的是什么？」 "45 分钟最想带走" 无目标则 5.2、8.1 连锁失效
3.4 「要走到那儿，眼下最需要先弄清哪一块？」 "先弄清哪一块" 最常被跳过，直接决定探索是否有着力点
6.7 「我听到的是___，这样对吗？」 "我听到的是___" PCC 对话不可能一次有效反映都没有
7.2 / 7.3 「你说 A 又说 B，放一起看到什么？」
或：「你说'必须___'，这个'必须'从哪儿来？」		 "放一起 / 必须从哪来" PCC 与 ACC 的分水岭，二选一即可
8.5 「接下来一周你想做点什么或想点什么？」 "做点什么或想点什么" 无设计则整场停留在探索层
8.9 「我们还有五分钟，你希望怎么用它收尾？」 "还有五分钟怎么收尾" 判定极明确，补救成本极低

四、6 时段完整清单（按教练对话流程）

每个时段列出问题类别，每类给出 3–5 种问法变体 + 理论上可触达的 marker。每时段问 2–3 个类别即可覆盖本时段所有 marker。
⚠️ 变体来源说明：每个类别下变体 1（标准版）多数直接引用 KB 里的 ✔ 例子或肌肉记忆卡 18 问口诀，可溯源；变体 2–5 一部分来自 failure-patterns.md 替代话术段（可溯源），一部分是按 KB 模式仿造（未经独立验证，可能与 KB 判据不完全吻合）。看时优先用标准版。

0–2 分　连接与许可
类别 1 · 关心当下型 理论上触达 2–3 条
  • 「今天状态还好吗？」（一句话连接，1 分钟内必须转入议题建立） 连接完直接接 3.1 的开场问，不寒暄不延展（防模式 11）
  • 「走进这间之前，你今天过得怎么样？」 比"状态还好吗"更具体，4.2 + 5.4（好奇心）
  • 「谢谢你今天来。开始之前我想先问一句——此刻的你，是一个什么状态？」 把 4.2（关心）和 5.1（回应完整的人）合并，4.4（邀请回应）也带上
理论上可触达： 4.2 5.1 5.4 4.4 注意：这一段不拿分也无所谓，挤时间才是关键
2–10 分　议题建立（必命中 3.1 / 3.4）
类别 1 · 目标锁定型 ★必中 · 理论上触达 3–5 条
  • 「今天这 45 分钟，你最想带走的是什么？」 最经典问法；客户答宽泛领域（如"聊聊团队"）必须继续收敛，否则 3.1 降 △
  • 「今天这 45 分钟里，你最想弄清楚的是什么？」 适合客户"想搞明白一件事"的取向
  • 「45 分钟结束的时候，你想带着什么走出去？」 比"最想带走"更聚焦"成果感"，3.1 + 8.1 闭环
  • 「假设 45 分钟后一切顺利，你觉得发生了什么，让你觉得今天值了？」 一句话同时锁定 3.1（目标）+ 3.2（成功标准）——但要确认客户理解"假设"只是修辞而非真建议
理论上可触达： ★3.1 3.2 8.1 5.3 雷区：客户答完不收敛 = 3.1 失守
类别 2 · 成功标准型 理论上触达 1–3 条
  • 「聊完什么样你会觉得值了？」 标准版；紧跟 3.1 之后分两句问，不能合并
  • 「你希望 45 分钟后，手里多了什么？」 隐喻版；客户不爱说"值不值"时改用
  • 「结束的时候，你希望自己处在一种什么状态？」 状态版；适合情绪/能量类议题
  • 「什么算做到了？你怎么知道你真的拿到了？」 最直接的"标准"问法
理论上可触达： 3.2 8.7 5.3
类别 3 · 意义探寻型 理论上触达 3–4 条
  • 「如果这件事成了，对你意味着什么？」 标准版；锚点是"对你"，不是"对公司"
  • 「为什么是现在？为什么这件事对你重要？」 把"为什么现在做"和"对你意义"打包问
  • 「解决了之后，你会变得有什么不一样？」 位移版；命中 6.5（自我感知）+ 7.1（就客户提问）
  • 「如果不解决，会怎样？解决了，又会怎样？」 对照版；同时探意义（3.3）和代价（3.4）
理论上可触达： 3.3 6.5 7.1 5.1
类别 4 · 着力点定义型 ★必中 · 理论上触达 2–3 条
  • 「要走到那儿，眼下最需要先弄清哪一块？」 最经典问法；判断权必须在客户手里
  • 「你觉得眼下挡在中间的是哪一块？」 障碍版；适合客户感觉"卡住了"
  • 「如果我们今天只解决一件事，你会选哪一件？」 强迫收敛版；当客户议题散乱时用
  • 「你已经试过哪些？哪一块最想有人陪你想清楚？」 背景版；同时摸清现状和优先级
理论上可触达： ★3.4 5.3 6.1 雷区：教练自己判断要处理什么 = 3.4 直接 ✘
10–20 分　探索现状（必命中 6.7）
类别 1 · 客户原词探索型 理论上触达 2–3 条
  • 「你刚才说'___'，对你来说是什么感觉？」 标准版；必须是客户的原词，教练替客户换词直接失分
  • 「你刚才用的那个词'___'——它对你来说，意味着什么？」 意义版；客户不爱聊感受时改问"意义"
  • 「你说'撑'，这个'撑'——具体是什么样的一种撑？」 具象版；适合隐喻词（撑、扛、堵、漂）
  • 「你前面用了'___'这个词——这个字是你习惯说的，还是第一次这么说？」 语用版；探索语言习惯，本身是 5.4（好奇心）
理论上可触达： 6.2 6.1 6.3 5.4
类别 2 · 情绪承接型 理论上触达 2–4 条
  • 「说到这儿，你心里什么感觉？」 经典版；客户情绪出现时不绕向行动（防模式 08）
  • 「听起来有点___，是这样吗？」 命名核对版；同时 4.2（表达同理）
  • 「这个'___'，如果它会说话，会说什么？」 隐喻版；适合客户表层理性但底层有情绪
  • 「这个担心，可以多说一点吗？」 邀请版；当客户刚表达完情绪时，鼓励继续
  • 「这个情绪——它在身体的哪个位置？」 身体版；适合深入情绪层
理论上可触达： 6.3 4.3 4.2 5.4 注意：这是 PCC 最容易"礼貌命中"的一条，要"准确说出感受"而非安慰
类别 3 · 非语言 / 能量探索型 理论上触达 2–3 条
  • 「我注意到你说到这儿的时候声音低下去了。」 经典版；必须明确邀请探索（vec-06 校准补）
  • 「你刚才笑了一下，那是什么？」 细微表情版；5.5（允许沉默）顺带
  • 「你停顿了很久——你愿意说说你刚才在想什么吗？」 停顿版；客户自发停顿 ≠ 5.5，但邀请本身 = 5.5
  • 「我注意到你讲到 A 的时候身体往后靠，讲到 B 的时候又坐直了——这对你来说意味着什么？」 对照版；要求有真实音频/视频场才能命中
理论上可触达： 6.4 5.5 4.4 注意：纯文字场少用；文字稿无停顿标记时即使问也判 ✘
类别 4 · 自我感知型 理论上触达 3–4 条
  • 「在这件事里，你把自己看成什么样的人？」 经典版；把客户从"事"拉到"人"
  • 「你觉得在别人眼里你是什么样的？」 他者版；探索自我感知的另一面
  • 「当你做这件事的时候，你是一个怎样的自己？」 情境版；锁定"此刻在这件事上"的身份
  • 「你说'必须扛住'——在扛的那个你，是什么样的你？」 原词 + 身份复合版；6.2 + 6.5 + 7.1 三连
理论上可触达： 6.5 7.1 5.1
类别 5 · 简洁反映型 ★必中 · 理论上触达 2–4 条
  • 「我听到的是___，是这样吗？」 标准版；必带确认问，否则 6.7 降 △ + 4.4 不命中
  • 「所以是___，但___——我听到的对吗？」 对照版；适合客户表达复杂时
  • 「你说的是___，我这样理解对吗？」 复述版；最简洁，6.7 最稳
  • 「如果用你刚才的词，是'___'——你愿意再确认下吗？」 原词回放版；6.7 + 6.2 双重命中
理论上可触达： ★6.7 4.4 6.1 6.2 雷区：只总结不确认 = 6.7 降 △；用教练词替换客户词 = 6.7 + 4.4 双丢
20–35 分　唤起觉察（必命中 7.2 或 7.3）
类别 1 · 并置唤醒型 ★必中 · 理论上触达 3–5 条
  • 「你刚才说 A，又说 B——放一起，你看到什么？」 经典版；A/B 必须是客户实际说过的内容
  • 「你前面说很难，又说必须扛住。这两个放一起，你想到什么？」 自带情绪词版；7.3 命中率高
  • 「你说想要 X，又说代价是 Y——这两件事在一起，对你来说是怎样的？」 价值冲突版；适合"想要但代价大"型客户
  • 「你开头说想___，现在又说___——这两个之间，有什么联系？」 时间轴版；适合议题漂移时拉回
  • 「你刚才那句'___'和你接下来那句'___'，听起来是矛盾的。你怎么理解这个？」 显式矛盾版；客户自我合理化时用（防模式 12）
理论上可触达： ★7.3 6.1 6.7 4.4 7.1 注意：等客户出现"我没这么想过"才算真命中，否则降 △
类别 2 · 原词追溯型 ★必中 · 理论上触达 3–4 条
  • 「你说'必须___'，这个'必须'从哪儿来？」 经典版；最易命中 7.2 的原词
  • 「你说'撑'——这个'撑'，从哪儿学来的？」 来源版；适合客户把"扛"内化为自我认知
  • 「你说'不能让他失望'——这个'不能'是谁的声音？」 内化他人版；探索客户内在的他人声音
  • 「你说'不想变成我爸'——这个'爸'在你脑子里，是个什么样的人？」 人物版；6.2 + 6.5 + 7.1 三连
  • 「你说'我怕搞砸'——这个'怕'，在你人生里，是什么时候第一次出现？」 时间版；直接探根源
理论上可触达： ★7.2 6.2 7.1 5.4 注意：7.2 / 7.3 二选一即可；客户出现"我没这么想 / 其实我……"才升 ✔
类别 3 · 身份位移型 理论上触达 3–4 条
  • 「如果不做那个'必须搞定一切的人'，你会是谁？」 经典版；身份层的 7.2
  • 「如果这个'必须___'消失了，你看到的是一个什么样的自己？」 移除版；适合"我必须 X"型客户
  • 「5 年后回头看今天，你希望那时的你是一个什么样的人？」 时间版；触发 7.3（关于事）+ 5.1
  • 「如果不是你最信任的人听到你说这话，他会怎么看你？」 他者版；多视角看自我
理论上可触达： 7.2 5.1 5.4 7.1
类别 4 · 低权重分享型 理论上触达 3–4 条
  • 「我有个感觉不一定对——___，对你来说是什么？」 标准版；分享前降权，分享后交出去
  • 「我注意到你说 A 时用的词是'___'——这跟你之前说的 B 有点不一样。这个观察对吗？」 语言观察版；不评判，只描述变化
  • 「我有个直觉——你其实已经知道答案了，只是还没准备好说。是不是这样？」 直觉版；客户常因此松动
  • 「我听到你说这件事的时候，底下好像有一个'但其实'——你愿意多说一点吗？」 未说出版；适合客户表达克制的场景
理论上可触达： 7.5 6.1 4.4 5.4 雷区：客户否定后"再推一次" = 7.5 直接 ✘，且 4.4 也丢
类别 5 · 朝向结果型 理论上触达 2–3 条
  • 「要到你说的那个状态，需要有什么不一样？」 经典版；7.4 + 7.1
  • 「什么会让你更接近它？」 最短版；7.4 命中
  • 「如果今天结束时你真的拿到了那个答案——从现在到那之间，最关键的一步是什么？」 路径版；7.4 + 8.4 桥
  • 「你已经做过的、让你靠近了它的事，是什么？」 资源版；不直接问结果，而问已有的接近
理论上可触达： 7.4 7.1 8.4 注意：3.1 未真正确认期望结果时，7.4 严格 △ 不升 ✔
35–42 分　设计与承诺（必命中 8.5）
类别 1 · 新学习运用型 理论上触达 2–3 条
  • 「刚才这个发现，你想拿它做点什么？」 8.4 桥；把"学习"和"未来"挂钩
  • 「这个新的看法，会怎么影响你接下来的做法？」 影响版；8.4 + 7.4 双重命中
  • 「这次约谈收获到的，会为你的未来创造什么？」 未来版；本土督导标志性问法
  • 「你刚才说'其实我是___'——这个发现如果留在你生活里，你想让它出现在哪里？」 具象版；锁定一个具体场景
理论上可触达： 8.4 8.5 5.3
类别 2 · 行动 + 反思设计型 ★必中 · 理论上触达 2–3 条
  • 「接下来一周你想做点什么或想点什么？」 标准版；"或想点什么"是关键，反思也算行动
  • 「从今天到下次见面，你想试什么？」 区间版；适合有连续教练关系的客户
  • 「约谈后你的行动是什么？有哪些新的思考？」 本土督导标志性问法；"行动 + 思考"并列
  • 「你想做点什么，让今天聊出来的不是停在今天的？」 连接版；防止"我会想想"敷衍
  • 「你刚才说的那个 ___ 想法，第一个想尝试的步骤是什么？」 具体版；逼出可执行行动
理论上可触达： ★8.5 8.4 5.3 雷区：教练布置作业"那你回去跟他谈一次"= 触发能力 1 红线
类别 3 · 资源 / 障碍型 理论上触达 2–3 条

六、雷区——看似多命中实际丢分的"伪多命中问句"

1. 看似问 ≥2 个 marker，其实一条都没拿到

  2. 「为什么这件事对你这么难？」——"为什么"指向原因而非意义，3.3 ✘；泛化问句 6.1 ✘；无原词 6.2 ✘。补救：改成"如果这件事成了，对你意味着什么"指向 3.3 + 6.5。

2. 多命中问句的反模式（看似命中但降档）

  1. 「你是不是觉得压力很大？」——诱导式，5.4 ✘（无好奇）+ 6.3 ✘（替客户断定情绪）。补救：改成"说到这儿，你心里什么感觉？"开放探索。

  3. 「所以你其实是个完美主义者。」——替客户下定义，6.7 ✘ + 4.4 ✘ + 触发能力 1 评判。补救：改成"我听到的是___，是这样吗？"用客户原词。

7.2 实证"多命中天花板"——L066 + L122 详析

⭐ L066 · 笑捕捉 + 命名(实证 2-3 命中) 实证命中 2–3

原问句：「好像担忧的部分占的更多，但刚刚听到你在说话的时候，其实是笑了一下。所以在那一刻有什么样子的想到的东西，会有不一样的东西吗？」

为什么能多命中：

  • 捕捉矛盾信号：客户表层说"担忧占更多"，但声音里有笑——教练先识别了非语言信号 (6.4)
  • 命名情绪 + 命名非语言：把"担忧"和"笑"并置邀请客户解释 (6.3 + 6.4 双命中)
  • "会有不一样的吗" 开放式收尾：邀请客户自由探索 (7.7 隐含命中)

v1 验证：这是 03 案例里"理论 2 实际 2-3" 的代表——形式和理论推论一致。

⭐⭐ L122 · 能量捕捉 + 反映(实证天花板 3 命中) 实证命中 3

原问句：「好像这一段的时候，客户乙的整一个能量还有点点起来哦，有点不一样，你感觉呢？」

为什么是 03 案例实证天花板：

  • 6.3 命名能量变化："整一个能量还有点点起来"——直接命名非语言信号
  • 6.4 探索能量变化："有点不一样" + "你感觉呢"——明确邀请客户探索
  • 6.7 简洁反映：反映客户当下的状态(但督导判 △ "非简洁但有"——长度超标)
  • 5.4 好奇心(隐含)：从"你感觉呢"可见

v1 验证：这是 03 案例里实际命中数最高的节点。3 条 ≈ 03 案例实际天花板。我的 TOP 10 理论推论的"4-5 条"在这个案例里未观察到。

7.3 实证反例——"理论 4 实际 0"三个节点

⚠ L054 · 分享观察(理论 4 → 实际 0) 实证命中 0

原问句：「我好像看到了这个东西，想要反馈给客户乙看看客户乙对我这样子的一个看法怎么看。」

为什么理论 4 实际 0：

  • 形式上像 7.5(分享观察)——但未降权重("我好像看到了" 实际是"我看到的是")
  • 未明确"交出去"动作("你怎么看"被埋在前一句)
  • 督导特别标注 7.5 ✘：结构判据全数违反

v1 警示：我的 TOP 10 #2 "低权重分享型"理论 4 命中——但若"降权重"和"交出去"任一动作缺失，立即从 4 → 0。这是 03 案例的实证证据。

⚠ L072 · 原词追溯(理论 4 → 实际 0 △) 实证命中 0 △

原问句：「抛开那些限制啊、时间啊，这种表面的担忧，你真正担忧的是什么？」

为什么理论 4 实际 0：

  • 形式上像 7.2(向内探索)——但偏封闭("真正担忧的是什么"是封闭式的"是什么")
  • 督导评注：「此问题偏封闭，应改为'第二曲线对你重要吗?它会给你带来什么?'等正向问题」
  • 客户虽答出"真正担忧的是..."但仍在原框架内——7.2 △ 不升 ✔

v1 警示：我的 TOP 10 #3 "原词追溯型"理论 4 命中——但若问句偏封闭或指向负向"担忧",即使有原词也会从 4 → 0 △。 督导建议"正向"问法替代"负向"问法。

⚠ L162 · 反思邀请(理论 1 → 实际 -2 含状态污染) 实证命中 -2

原问句：「你觉得足够吗?」

  • 形式上像 4.4(邀请回应)——但偏封闭 + 不相信("足够吗"暗示不信任)
  • 督导师-5 教练原话：「这种其实是一个比较重要啊，要去处理的问题...因为教练评估这一块...他实际上可以问他的...这种足够吗，这件事情好像是有点不太相信啊。偏封闭哈」
  • 状态污染：不仅自身 0 命中，还把后续 L184 收尾 8.9 拖到 △(原本可能 ✔)

v1 警示：这是 03 案例最严重的反例——单句失分可传染。 KB 没明确说"状态污染"，但 03 督导实际判定里 L184 因 L162 而 △。这条 v0 草稿没预测到。

7.4 v1 核心发现（v0 → v1 修订）

  1. 理论 vs 实际平均差 2-3 倍：03 案例 20 节点里，平均实际命中 1 条/问；TOP 10 理论推论平均 3.7 条/问。真实单问命中天花板是 3 条(L122)，不是 4-5 条。
  2. "形式 4 实际 0"三个反例(L054 / L072 / L162)揭示关键动作缺失是隐形杀手：降权重 / 交出去 / 正向 / 开放——任一缺失即从满分到 0。
  3. 必命中项实际 1 ✔ + 5 △：8.5 ✔；3.1, 3.4, 6.7, 7.2, 8.9 全 △。这反映 P1 边缘水平。03 案例整体 ✔ 率 35.1%(KB 完整 37 markers 映射表确认)。
  4. 状态污染是隐藏维度：L162 "足够吗" 不仅自身 -2 命中，还把 L184 8.9 从潜在 ✔ 拖到 △。v0 草稿没预测到，v1 加上作为新警示。
  5. 唯一经过真人验证的多命中模式：L066(2-3 命中) + L122(3 命中天花板)——共性是非语言捕捉 + 命名 + 邀请探索。这应是 PCC 备考的"实证多命中样板"。

v1 局限性：仅 03 案例 N=1。04 / 05 案例的督导反馈是整体性 / 模式化，无逐节点 marker 判定(已扫 02 案例督导段确认)， 所以无法扩展到多案例共现矩阵。要做真正的 v2 多案例共现，需要补 04 / 05 案例的逐节点判定（每份半天工作量）。
